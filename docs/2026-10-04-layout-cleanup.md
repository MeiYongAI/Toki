# 页面布局净化

## 用户设置

功能页的“页面布局净化”板块提供顶部导航、底部导航、视频页面三个独立入口，各自打开对应开关列表。开关打开表示隐藏对应控件，默认全部关闭。首次启用需要重新打开 TikTok，使该功能的 Hook 在当前进程安装；安装后的独立开关变化通过现有配置订阅应用。

视频页面包括作者头像、头像关注按钮、点赞、评论、收藏、转发、音乐唱片、作者信息、文案内容、音乐信息、信息标签、搜索标签、停止连播按钮。音乐唱片与音乐文字分别控制。“信息标签”指原生信息标签容器，文案中的内联话题随文案一起隐藏，不修改文本内容或视频画面。

顶栏和底栏分别保存开关。“社区”对应官方宿主的 `homepage_explore` 栏目标识。模块按原生标签匹配，不使用显示文本、位置序号、固定资源编号或版本判断。隐藏的是入口视图，原生页面和页面选择控制器继续存在。

全部 58 套资源同步更新。三个分类直接显示，开关行文字自然换行；弹窗内容高度受屏幕可用空间约束，列表可以滚动。

## 显示管理

`HostViewVisibility` 为自动净屏和布局净化共用的唯一 `View.setVisibility` 拦截器。`CleanViewGate` 保存宿主请求的可见性和多个所有者。布局净化的 GONE 优先于播放净屏的 INVISIBLE；暂停不解除独立隐藏，关闭独立隐藏也不解除仍然生效的净屏。

容器创建或重新绑定时登记完整控件。宿主后续的显示调用继续经过相同决策，无定时轮询、全窗口遍历或取消绘制。GONE 同时禁止点击并交回父布局分配空间。使用弱引用表，后台预加载和主线程共享同步状态；后台绑定只提交当前创建的视图。

顶栏：原生栏目绑定方法返回的栏目包装对象，按 `tag()` 识别栏目，排除其所属整条顶栏引用后取得唯一栏目视图。

角落入口：原生工具栏给控件设置语义标签的入口，覆盖搜索和直播及其按钮容器。

底栏：原生按钮的数据构造器提供栏目标签，按钮构造完成后绑定。无需更改 FragmentTabHost 的页面记录。

视频页面：已确认的独立组件 `onViewCreated(View)`，继承同一方法的组件按实例类型过滤，共用 Hook 只安装一次。停止连播按钮绑定原生 AutoScrollComponent 的视图，不依赖自动连播增强开关；长按菜单仍可停止连播。头像关注按钮取头像组件唯一 `ViewGroup` 字段，整个头像与关注按钮分别控制。
